# Shopify AI - Product Search & Chat

An AI-powered product search and chat system using OpenSearch vector embeddings and AWS Bedrock.

---

## 📋 Quick Overview

This project has two main capabilities:

1. **Fast Vector Search** - Find products using natural language queries
2. **AI Chat** - Get conversational responses about products

Everything is powered by:
- **OpenSearch Serverless** - Vector similarity search
- **AWS Bedrock (Titan)** - Text embeddings & LLM responses
- **FastAPI** - REST API endpoints

---

## 🚀 Getting Started

### 1. Setup Environment

Copy the example environment file and fill in your AWS credentials:

```bash
cp env.example .env
```

Required environment variables:
```
OPENSEARCH_HOST=https://xxx.aoss.amazonaws.com
AWS_REGION=us-east-1
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Create Product Embeddings

This is the most important step. It reads your product catalog and creates vector embeddings for search:

```bash
python create_opensearch_db.py
```

The script will:
- Ask you to select a JSONL catalog file from the `data/` folder
- Create an OpenSearch index (or use existing one)
- Generate embeddings for each product using AWS Bedrock
- Upload vectors to OpenSearch

**What it does technically:**
- Reads product JSON from `data/*.jsonl`
- Calls `create_embedding()` in `create_opensearch_db.py` to generate Bedrock embeddings
- Stores vectors in OpenSearch with KNN (k-nearest neighbors) indexing

### 4. Run the API

```bash
python search_api.py
```

The API will start at `http://localhost:8000`

## 🔍 How Search Works

### `/search-fast` Endpoint

**Request:**
```json
{
  "query": "red shoes under $100",
  "k": 5,
  "collection_name": "products"
}
```

**What happens:**
1. Query is cleaned and converted to an embedding by `create_embedding()`
2. OpenSearch performs KNN search against stored product embeddings
3. Filters (like price) are extracted from the query
4. Top matching products are returned (target: <200ms)

**Code flow:**
```
search_fast() → search_products_opensearch() → create_embedding() → KNN search
```

## 💬 How Chat Works

### `/chat` Endpoint

**Request:**
```json
{
  "message": "I'm looking for comfortable running shoes",
  "k": 5,
  "collection_name": "products"
}
```

**What happens:**
1. User message is searched for relevant products (same as `/search-fast`)
2. Top results are sent to AWS Bedrock LLM
3. AI generates a conversational response about those products
4. Response includes product links and reasoning

**Code flow:**
```
chat() → search_products_opensearch() → generate_chat_response() → Bedrock LLM
```

Generated by: `services/ai_services.py` → `generate_chat_response()`

## 🧠 How Embeddings Are Created

The embedding process happens in `create_opensearch_db.py`:

1. **Read Products** - Load JSONL catalog file
   ```python
   # Each product has: product_id, title, text, price, category, tags, url, image
   ```

2. **Build Embedding Text** - Combine product fields
   ```python
   build_text_for_embedding() # Combines title + description + category + tags
   ```

3. **Generate Embedding** - Call AWS Bedrock
   ```python
   create_embedding(text) # Returns 1536-dimensional vector
   ```

4. **Upload to OpenSearch** - Batch upsert with KNN indexing
   ```python
   bulk_upsert_documents() # Stores vectors in OpenSearch
   ```

**Key functions:**
- `create_embedding()` - Generates embeddings using Bedrock Titan model
- `build_text_for_embedding()` - Formats product data for embedding
- `process_single_product()` - Wraps a product with its embedding
- `bulk_upsert_documents()` - Uploads batches to OpenSearch
- `embed_products_to_opensearch()` - Main orchestrator function

## ⚙️ Configuration

### OpenSearch Vector Index

Defined in `create_opensearch_db.py`:
- **Index name**: `products` (configurable)
- **Vector dimension**: 1536 (Bedrock Titan output size)
- **Vector algorithm**: HNSW (Hierarchical Navigable Small World)
- **Similarity metric**: Cosine similarity

### AI Behavior

Edit `config/sys_prompt.txt` to change how the AI responds to user queries.

## 🔧 Troubleshooting

**No embeddings created?**
- Check AWS credentials in `.env`
- Verify `data/catalog.jsonl` exists and has valid JSON

**Search returns no results?**
- Run the embedding script again
- Check that products exist in OpenSearch: `GET http://localhost:9200/products/_count`

**Chat responses are off-topic?**
- Edit `config/sys_prompt.txt` to guide the AI better
